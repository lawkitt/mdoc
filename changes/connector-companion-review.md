- **Review in the companion.** Behind "AI connector (preview)", a review
  request in the companion lists the document's proposals, shown only
  while the pointer is over them, with Replace all: it runs the document's
  own review in mdoc's window, which stays behind, and the save makes it
  Ready by the same rules, so the AI app's next read gets it. Anything
  else goes through Open in mdoc, which opens the review in front
  (Milestone 2 item 16, [#1164](https://github.com/lawkitt/mdoc/issues/1164)).
