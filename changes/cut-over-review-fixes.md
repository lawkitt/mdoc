- **Copy for AI checks the document as the shelf does, and the cut-over
  keeps edits.** In the editor, Copy for AI (the Share tab, the menu and
  its shortcut) copies nothing while a name the Project knows is still
  written out or a proposal is left, and says why; Copy Markdown still
  copies the text as it is. Delete Project deletes only the documents it
  asked about, and Move to Unfiled saves open edits first or stops. A quit
  saves a keystroke typed while it saved. A conversion's warning comes
  back after a restart, a missing original no longer hides its Markdown,
  and a file replaced at its path imports its new contents. Export
  Project exports nothing while an edit is unsaved, and writes an empty
  `.md` for a converted text its user cleared.
