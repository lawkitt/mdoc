- **Documents save themselves.** New and pasted documents live in mdoc's
  encrypted Vault from their first keystroke and save as you type, with
  their replacements, so there is no unsaved dot, save question or quit
  question, and a reopened document needs no rescan; Save writes at once.
  Save As is now Export Markdown…, which writes a copy and leaves the
  document where it is. The tab list remembers documents by id, never by
  title or path. Without a system key store, Home says why documents are
  unavailable and nothing can be added.
