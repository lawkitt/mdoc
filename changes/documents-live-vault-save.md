- **Documents live in the Vault and save themselves.** Every file you open,
  drop or paste, and every new document, becomes a document in mdoc's
  encrypted Vault, with the file kept as its original; it saves as you
  type, with its replacements, so there is no unsaved dot, save question or
  quit question, and a reopened document needs no rescan. Opening a file
  mdoc already holds asks once whether to open the existing document or
  import it again. Save writes at once; Save As is now Export Markdown…,
  which writes a copy. The tab list remembers documents by id, never by
  title or path. Without a system key store, Home says why documents are
  unavailable and nothing can be added.
