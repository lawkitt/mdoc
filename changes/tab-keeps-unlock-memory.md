- **An unlocked document stays unlocked while its tab is open.** After its
  password, a locked Word, Excel or PowerPoint file converts again, and its
  preview reloads, without asking; the tab keeps the unlocked document in
  memory only and drops it when the tab closes. The session never saves it,
  so reopening the document asks again (part of
  [#1024](https://github.com/lawkitt/mdoc/issues/1024)).
