- **The mobile core keeps each import's original in the Vault.** A
  document's first save into the Vault keeps the file it came from,
  encrypted: a locked file stays locked, and a photo is kept without its
  metadata. A repeated import of the same file is found, and the original
  is viewed from a copy in a folder the app names, or in memory when it is
  small. Both apps still use the old library until they switch
  ([#1091](https://github.com/lawkitt/mdoc/issues/1091)).
