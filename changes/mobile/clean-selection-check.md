- **The core tells whether a selection is clean.** For text you select,
  it says whether the document was scanned, whether that text changed
  since, how many proposals are in it and whether a name its Project knows
  is written out in it. "Replace N and copy" replaces those proposals as
  one undo step. The copy menus of a later release are built on it
  ([#1209](https://github.com/lawkitt/mdoc/issues/1209)).
