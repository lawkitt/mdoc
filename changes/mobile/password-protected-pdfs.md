- **Password-protected PDFs import on the phones.** A locked PDF asks for
  its password on the same card as a locked Word file and imports once
  Unlock opens it; a wrong password asks again, encryption mdoc can’t open
  says so, and a PDF locked only against editing opens as before. Its
  recognized pages are never kept to resume. On iOS its Original unlocks in
  memory while the document is open, and asks again once it reopens; mdoc
  never saves the password or an unlocked copy
  ([#1024](https://github.com/lawkitt/mdoc/issues/1024)).
