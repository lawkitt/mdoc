- **Password-protected Word files import.** A locked DOCX asks for its
  password on the document and imports once Unlock opens it; a wrong
  password asks again. On iOS, the open document keeps the unlock in memory
  so it can show the Original and its comments. Reopening the Original from
  saved Markdown asks for the password again. On Android, comments count
  in the left-out line
  (part of [#1007](https://github.com/lawkitt/mdoc/issues/1007)).
