- **Not a name.** A name found by mistake can come off with no trace: Not
  a name, at the end of the replacement popup's category menu (the only
  item there for a kept name) and of a Replacements row's menu, takes the
  mark off in the scope shown. Replaced text returns to its original, no
  list gains an entry (a hand-marked wording leaves Always), and the case
  drops the wording on its next save unless another member still uses
  its alias. Undo brings it back
  ([ADR 0122](https://github.com/lawkitt/mdoc/blob/b5ac9dba6c9aa8ce79029722ac906ce4e44a5bac/docs/adr/0122-not-a-name.md)).
