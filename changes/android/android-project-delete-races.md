- **Deleting a Project keeps open documents in step.** A document whose
  first save ends as its Project is deleted moves to Unfiled or is deleted
  with the rest. A move to Unfiled that stops part way opens the documents
  it moved again in Unfiled, so they keep saving, and then shows its error.
  A Project page's Replies and Names no longer go empty when the page
  opened before it finishes loading late
  ([#1091](https://github.com/lawkitt/mdoc/issues/1091)).
