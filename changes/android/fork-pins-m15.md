- **A sentence that matches the header stays in the body of a sparse
  page.** On a PDF page with only a line or two, such as a short last page,
  a line with the running header's words is removed only where the header
  sits; the same sentence in the page's body stays and is no longer counted
  as a repeated header line
  ([#925](https://github.com/lawkitt/mdoc/issues/925)).
