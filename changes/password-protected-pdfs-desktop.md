- **Password-protected PDFs import.** A locked PDF asks for its password on
  the same card as a locked Word, Excel or PowerPoint file, imports, and
  shows its Original, all in memory: mdoc keeps the password only while the
  tab is open and never saves it or an unlocked copy. A wrong password asks
  again; encryption mdoc can’t open says so; a PDF locked only against
  editing opens as before. A reopened tab’s Original asks for the password
  again (#1024).
