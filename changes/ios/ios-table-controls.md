- **Table controls live in the toolbar.** With the caret in a table's cell,
  the toolbar above the keyboard offers Row below, Column right and a ⋯ menu
  with Row above, Column left, Delete row, Delete column, Align column and
  Delete table; after a new column the table scrolls to it. The table panel
  is gone: Aa is the formatting keyboard in a cell too, so strikethrough,
  inline code, highlight and links work there, and Aa, not a Keyboard key,
  brings the system keyboard back
  ([ADR 0110](docs/adr/0110-mobile-editor-polish.md)).
