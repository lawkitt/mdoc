- **Text recognition gives memory back between pages.** A scanned PDF's
  import no longer keeps the working memory of its biggest page until the
  app quits: at the default 150 dpi, an import of many pages holds about
  0.8 GiB on an iPhone 17 Pro instead of 1.7 GiB, with the same text and
  about the same speed ([#925](https://github.com/lawkitt/mdoc/issues/925)).
