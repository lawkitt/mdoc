- **Lists read evenly.** Bullets, numbers and task boxes start at the
  paragraph's left edge and their text shares one column, each nested level
  one column further; a list with two-digit numbers widens all its items
  together. Bullets and numbers are in the text colour, the bullet a little
  larger than the text. In edit mode the caret's line shows its `-`, `1.` or `- [ ]` in the
  same column, so the text no longer jumps sideways
  ([ADR 0110](docs/adr/0110-mobile-editor-polish.md)).
