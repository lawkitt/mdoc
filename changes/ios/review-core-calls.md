- **The shared core can undo review steps and change identities.** Each
  Replace, Keep, Replace all, mark, rename, category change, Same as, New
  alias, owner change and case join is one step of a 256-step undo history,
  and the core renames, recategorizes, links and splits identities the way
  the desktop does, with the merge hints a dismissal keeps hidden in the
  case. The review bar (ADR 0098) builds on these calls.
