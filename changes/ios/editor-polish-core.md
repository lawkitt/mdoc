- **Editing polish in the editor core.** The list, task and block buttons
  reach every paragraph a selection touches, skip its blank lines and turn
  them all back into text when each is that kind already. Italic on a bold
  selection gives bold italic. Row above or below and the new columns put
  the caret in line with where it was; Return in a table's last row adds a
  row, and on an empty one leaves the table. Ordered lists show the number
  written (`9.` shows 9.)
  ([ADR 0110](docs/adr/0110-mobile-editor-polish.md)).
