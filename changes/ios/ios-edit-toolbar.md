- **Editing toolbar, formatting keyboard and links.** In edit mode a glass
  bar above the keyboard holds undo, redo, bold, italic, list, task,
  indent, outdent, Aa and hide keyboard; a button is on while the caret is
  in what it makes and off where it cannot apply. Aa swaps the keyboard for
  formatting keys: turn the line into text, a heading, a quote, a code
  block or a callout, strike, inline code, highlight, link, rule and table.
  With the caret in a link a chip offers Open (web links only) and Edit;
  the Link key and ⌘K open a sheet for its text and address. A typed
  opening code fence closes itself. On a hardware keyboard ⌘B, ⌘I, ⌘K, Tab
  and ⇧Tab work and are listed when ⌘ is held. Each button is one step for
  Undo ([ADR 0109](docs/adr/0109-mobile-markdown-editor.md)).
