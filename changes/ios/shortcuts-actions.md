- **Pseudonymize text and Restore text in Shortcuts (preview).** With
  Settings › AI connector (preview) on, Pseudonymize text adds text as a
  new document in a Project or Unfiled and opens it for review, and stops
  the shortcut until you have reviewed it; Restore text returns an AI
  reply with the real names, using a Project or the place shared last, and
  saves nothing ([#1164](https://github.com/lawkitt/mdoc/issues/1164)).
