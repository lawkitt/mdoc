- **New document, Find names again and an editable sample.** New document,
  first in the + menu, opens an empty document in edit mode with the
  keyboard up; it is named after its first line until you rename it, and
  an untouched one leaves no row behind. Find names again, in the
  document's menu outside edit mode, proposes names in text typed since
  the first Find names. Try a sample again restores the sample's text,
  asking first if you edited it
  ([ADR 0109](docs/adr/0109-mobile-markdown-editor.md)).
