- **Moves, deletes, quits and imports keep the latest edits.** A name
  applied while a move waits moves with its document and keeps its person,
  and Move to New Project no longer reports a failure after it moved.
  Deleting Unfiled documents deletes nothing when one moved into a Project
  while it asked, and asks again. A quit writes notes and a reply typed
  while it saved, and Export Project exports notes typed while it waited.
  Correcting a reply keeps a promoted document's link to it. Import Again
  stores the Markdown and the original from the same bytes. A document
  with a proposal left still shows Needs review after a restart.
